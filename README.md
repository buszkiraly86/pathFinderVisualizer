# pathFinderVisualizer

An interactive Dijkstra's algorithm visualizer built with React. Draw walls with the mouse on a grid, then watch the algorithm explore the frontier and trace the shortest path back to the source.

Live demo: https://buszkiraly86.github.io/pathFinderVisualizer

## Features

- 25x50 grid with configurable start and end points
- Click and drag to draw walls
- Animated frontier exploration and path reconstruction
- Reset and re-run

## Getting started

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Deployment

Deployed to GitHub Pages via the `gh-pages` package:

```bash
npm run deploy
```
